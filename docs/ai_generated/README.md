# AI Generated Documentation (`docs/ai_generated/`)

Este directorio contiene documentos de investigación técnica, notas explicativas de arquitectura y guías conceptuales redactadas con asistencia de IA (Antigravity).

### Política de Transparencia
En consonancia con la [Política de Transparencia del Proyecto](../../README.md#ai-transparency-policy):
- Todos los documentos de análisis, guías pedagógicas o síntesis teóricas generados por el modelo de IA se aíslan en este directorio para diferenciarlos claramente de las notas redactadas de forma manual por humanos.
- El objetivo de estos documentos es servir como laboratorio de aprendizaje continuo sobre la arquitectura ARM11, el compilador ARMCC (RVCT 4.x), la convención AAPCS y la ingeniería inversa de Nintendo 3DS.
